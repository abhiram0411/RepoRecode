Practice now resolves small interface inheritance trees, including renamed imports/reexports, multiple distinct bases, optional and readonly inherited fields. Duplicate/overridden fields, diamond duplicates, cycles, merged declarations, unbounded structural constraints, qualified or non-interface bases and oversized/deep shapes remain unsupported. Existing bounds remain: depth 8, 256 expansion visits, three properties per object, two object levels/three leaves, 16 object samples and 64 probes. Analysis version 15 refreshes old indexes.

Default generic arguments resolve in declaration scope, including defaults referring to earlier parameters and defaults on inherited/imported interfaces. The read-only type context preserves defaults with imported type names expanded locally. Missing required arguments, forward/self references, invalid required-after-default ordering and shapes outside the existing bounds remain unsupported. Local continuation supports independent and earlier-parameter scalar constraints (number/string/boolean, null/undefined and bounded literal unions), validates concrete arguments and defaults, and preserves extends clauses in the isolated type context. Object constraints now support bounded structural subset checks; forward/self constraints and unresolved constrained wrappers remain unsupported; finite probes do not establish general generic correctness. This continuation is not deployed.
